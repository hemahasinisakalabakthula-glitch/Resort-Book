# ResortBook - Resort Booking Website

A simple resort booking website built using HTML, CSS and JavaScript.

## Features

- Resort search by location
- User registration and login
- Resort details
- Resort booking
- My Bookings section
- Form validation
- LocalStorage for saving user and booking data
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## Project Description

ResortBook is a frontend resort booking website that allows users to search for resorts, view resort details, register/login, and make bookings.
